# React Base — фактический статус

Обновлено: 24 сентября 2026.

Рабочая React-база собрана и подготовлена для визуальной приёмки по фазе 5 директивы. Реализация и автоматические проверки завершены; полная попиксельная идентичность всех вариантов не заявляется. Итог и границы проверок — в [react-base-report.md](react-base-report.md).

## Готово

- Vite + React + TypeScript, зависимости установлены; локальная страница запускается на http://localhost:5173/.
- Перенесены 456 переменных с учётом 273 локальных Elastic, 81 продуктовой и 102 внешних зависимостей; 29 исходных Text Styles.
- Реестр: 204 позиции Elastic и 23 продуктовые, 3 811 сочетаний вариантов.
- Страница компонентов, палитры и типографики; поиск, выбор варианта и ссылки на исходные узлы Figma.
- Полный прогон рендера: 227 компонентов, 3 811 вариантов, без ошибок и сообщений консоли. Это проверка работоспособности, не подтверждение визуальной точности всех вариантов.
- Проверены 456 токенов в шести сочетаниях темы и масштаба; расхождений с выгруженным манифестом нет. Подключены Inter и Roboto Mono, проверены восемь используемых сочетаний семейства, начертания и веса.
- Исправлены фильтрация, поиск и настоящая пагинация таблицы участников; проверены совместные фильтры, пустой результат, сброс и границы страниц.
- Проверены Checkbox (Mixed → On → Off), клавиатура, смена входных свойств, disabled; выбор результата задания двумя равнозначными Radio и доступность «Далее» после выбора.
- На ширине 390 px страница каталога не создаёт горизонтального переполнения.
- Уточнены адаптеры DataGrid, DatePicker, Loading, Selectable, Steps; подключены отдельные мосты исходной Elastic-темы и продуктовых токенов.
- Последние проверки TypeScript, lint и production build прошли. Сборка предупреждает о крупном JS-пакете каталога; оптимизация загрузки ещё не выполнена.
- Иконки намеренно представлены прозрачными заглушками по директиве.

## Уточнения заключительного прохода

- Добавлены отдельные адаптеры внутренних частей Form, Markdown, Page Layout, Popover, Range, SuperDatePicker, Tour, Table; разделены служебные пояснения и поля.
- Таблица сценариев перенесена с отдельной поверхностью, полным набором показателей и рабочим выбором. Уточнены группы фильтров/фасетов, карточки выбора и список уведомлений.
- Исправлено влияние CSS каталога на подписи Radio; текстовые и логические свойства вынесены в отдельные контролы каталога.
- Полный рендер 227 / 3 811 повторно прошёл без сообщений консоли; последующие затронутые группы проверены адресно. Добавлены семь групп проверок поведения адаптеров.
- Подготовлены корневой README, постоянный отчёт и проверка ссылок на CSS-токены. После правок TypeScript, lint и production build проходят.
- Завершена сверка ReplayControls, AutoRefresh, компактных дат, миниатюр, карточек выбора, групп аватаров и диапазона. Добавлен настоящий список выбора попыток.
- Исправлена нулевая высота содержимого навигации в dev-режиме EUI 106; добавлены 11 проверок заключительных исправлений, включая фактическое раскрытие/сворачивание, палитру аватаров и границы перемотки.

## Границы приёмки

- Визуальная сверка с Figma выполнена адресно. Не проведена отдельная попиксельная приёмка каждого из 3 811 вариантов; количество фасадов и успешный рендер не доказывают полного визуального совпадения.
- Иконки и иллюстративные изображения остаются местами для контента. Интерфейс каталога использует демонстрационные данные и callbacks, без серверной аналитики.
- Сборка каталога выдаёт предупреждение о размере JS. Разделение загрузки приложения ещё не выполнялось.

Storybook запущен по прямому поручению пользователя; текущий состав и проверки отражены в `ds/storybook-report.md`. По следующему указанию пользователя плейсхолдеры иконок заменены исходными SVG библиотеки и логотипом из Figma.

Отчёты проверок: `.tmp/react-base/render-audit.json`, `interaction-audit.json`, `token-audit.json`, `completion-audit.json`. Скрипты воспроизведения находятся в `execution/check_react_*.mjs`.

## Смежные задачи Figma

Два типа ссылки добавлены на LaunchActive, созданы чистые desktop/mobile интерфейсы и детали участника без панели. Правила отражены в PRD, IA и реестре `ds/screens/_index.md`.
В desktop/mobile ParticipantSession разделены выбор результата и «Далее»; макеты статические, переключение состояний не связано в Figma-прототипе.
Пагинатор перестроен, экспорты обоих экранов проверены. Проверка живого редактора остаётся отдельной.
