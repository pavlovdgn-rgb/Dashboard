## Два типа ссылки — утверждено пользователем

- **С панелью UX-Lab:** участник видит задание, два равнозначных варианта результата и отдельную кнопку «Далее». До выбора результата кнопка недоступна. Самооценка не заменяет результат проверки событий.
- **Только интерфейс:** после открытия ссылки виден только подключённый интерфейс. Панели, подсказок, вопросов, кнопок перехода и экрана завершения UX-Lab внутри него нет. Сборщик передаёт действия в то же исследование; произвольная ссылка без подключённого сборщика этого не обеспечивает.
- Тип ссылки независим от режима «Задания / Свободное изучение». Без панели задание и информацию об участии передают заранее. В режиме заданий результат определяется настроенными критериями; отсутствие события само по себе не равно отказу участника. Если оснований для оценки недостаточно, показывается «Нет оценки». В свободном изучении успешность задания неприменима.
- В деталях участника сохраняются тип ссылки и источник оценки. Правила начала/завершения сессии, повторного входа и границ попыток требуют реализации по D03; способ интеграции и доставки — D09. Они не заменяются выдуманным таймаутом.

Это согласованный сценарий и макеты. Реальный сбор, выдача URL, буфер обмена и серверная оценка пока не реализованы. URL с example.test — демонстрационные.

Выбор результата: композиция существующих Elastic Radio и ProductButton, не новый компонент библиотеки. Два ответа равнозначны; «Далее» — отдельное действие. Макеты: 210:11819 и 210:17090.

`SignalViewSwitch` — композиция EuiButtonGroup с двумя взаимоисключающими сегментами «Отдельные события» / «По страницам». Оба режима остаются в одном разделе; вкладки «Сигналы / Находки» сохраняются отдельно. Используются background/sidebar, accent/soft, accent/strong, text/secondary, border/focus и motion/feedback. Выбор доступен через aria-pressed и клавиатуру. Применён в реальном интерфейсе и компонентном примере; Figma-библиотека не изменялась.

Композиция существующих ProductButton (Secondary, arrowDown) + EuiPopover + EuiContextMenuPanel/Item. Макет закрытых фильтров: Dashboard `298:2900`. Открытые пункты используют `size/small` 8 по вертикали и `size/medium` 12 по горизонтали; внутри панели `size/x-small` 4. Цвета background/surface, text/primary, surface/hover, border/focus. Иконки arrowDown, check и layers — исходные Elastic UI.

Реализация `ProductDropdown.tsx` заменяет системное меню select только в продуктовых фильтрах таблицы и выборе попытки. Выбранный пункт отмечен галочкой и aria-checked; меню поддерживает стрелки, Enter, Escape и возврат фокуса. Это композиция в коде, не новый компонент или изменение библиотеки Figma.


### Режим и результат исследования · приложение · 28 сентября 2026
Режим использует существующую композицию EuiButtonGroup + оформление SignalViewSwitch: `accent-soft`, `accent-strong`, радиусы и spacing продукта. Отдельная новая библиотечная сущность не создавалась. Навигация исследований — композиция NavMenu, иконок document/arrowDown и существующих navItem. Подтверждение копирования — EuiToast. «Доля кликов» в приложении удалена по решению пользователя; её заменяет самостоятельный блок результатов задания с MetricRatio. Старый макет Figma обзора не является источником этой новой метрики.
# Критерии успеха и сводка · 28 сентября 2026

Предложение редактора критериев находится на существующей странице `382:2`: [ручная оценка](https://www.figma.com/design/1LeVoicxDT7Sl8TpMPs4hr?node-id=415-468), [автоматическая проверка](https://www.figma.com/design/1LeVoicxDT7Sl8TpMPs4hr?node-id=415-469), [неподключённое событие](https://www.figma.com/design/1LeVoicxDT7Sl8TpMPs4hr?node-id=415-470). Использованы ProductField, ProductButton, ProductTab, Inter, смысловые цвета продукта. Это предложение, а не реализованный универсальный конструктор. Описание результата свободное; автоматическое условие связано с конкретным прототипом и должно пройти пробную проверку. Ручная оценка допускает «невозможно оценить».

В приложении сводка адаптирована через существующий SummaryMetric: заголовок, значение, основание расчёта, детализация и переход. Счётчик сигналов показывает уникальные сессии, число серий дано отдельно. Полнота записи не рассчитывается из одного наличия видео/снимков. Шаги воронки размещены внутри Card; кнопки общих обновлений убраны из шапки, данные опрашиваются каждые 2 секунды. Повтор при ошибке и проверка подключения сохранены.
