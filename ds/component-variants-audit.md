# Component variants — выполнено в согласованном объёме

22 сентября 2026. Пользователь согласовал автономное определение состояний для текущих экранов. Прочитаны все 204 исходных элемента в Figma, сверены 3 продуктовых набора и фактически применяемые instances.

## Расширено

| Компонент | Матрица | Результат |

| ProductNavItem | Selected False / True × Default / Hover / Pressed / Focus | [8 вариантов](https://www.figma.com/design/1LeVoicxDT7Sl8TpMPs4hr/Dashboard?node-id=128-563) |

ReplayControls ранее расширен до 4 вариантов; HeatmapLegend оставлен с 2, DataCoverage — с 3 по решению пользователя. Всего в продуктовом UI Kit 6 наборов и 43 варианта.

## Почему именно эти изменения

Button применяется в UI Kit и экранах (35 и 88 instances на момент чтения, включая вложенные). У Neutral/Small есть только обычные Empty/Filled/Default ячейки. Наличие Disabled/Loading в общей оси не означает наличие этих комбинаций. Hover, Pressed и Focus добавлены локально вместе с Disabled и Loading.

Side Nav Item нужен общей боковой навигации, Tab — вкладкам сигналов/находок. Selected сохранён отдельной осью, Focus не снимает выделение. Расширения — оболочки с вложенными instances исходной библиотеки; отсоединения не выполнялись.

Text field, Textarea, Search и Select уже содержат Focus/Invalid/Disabled. Checkbox и Radio содержат выбор/фокус/блокировку, Table Cell — Hover/Selected/Disabled, Header — сортировку, Pagination — состояния внутренних кнопок. Загрузка результата, ошибка сервера и пустая выборка относятся к контейнеру/SharedPatterns, не к каждой легенде или строке.

## Проверка и границы

Проверены все 34 новые ячейки: уникальность матрицы, сохранение instances, размеры, отсутствие выхода ячеек за набор, привязки fills/strokes, Text Styles, положительных Auto Layout отступов и радиусов. Все три матрицы просмотрены на снимках. Исходные 9 продуктовых вариантов повторно прошли аудит. Это состояния макетов, не работающий проигрыватель и не кликабельный прототип. Перевод всех low-fi экранов в финальный UI не выполнялся.

Созданы 5 semantic aliases на существующую палитру; новых hex нет. Исходная Elastic UI сохранена. Названия и Deprecated-маркеры исходных элементов не менялись.
