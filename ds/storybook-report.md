# Storybook UX-Lab

24 сентября 2026. Каталог создан по `directives/directive_storybook.md` из существующей React-базы. Figma использовалась только для чтения источников иконок и логотипа.

## Состав

- Storybook 10.6.0, React/Vite, Docs и Accessibility. Локальный адрес: http://localhost:6006/.
- 227 из 227 компонентов: 204 Elastic UI и 23 UX-Lab. Пропущенных записей нет.
- 3 811 исходных сочетаний вариантов: отдельные именованные истории и AllVariants. Матрицы не достраивают отсутствующие в источнике сочетания.
- Autodocs у каждого компонента: свойства Figma, React-свойства и обработчики, Controls, Show code / Copy code с импортом настоящего фасада.
- Foundation: 393 уникальных Primitive CSS-переменных, 458 Semantic CSS-переменных, 29 исходных Text Styles. Это счёт CSS-имён, а не число переменных Figma: реестр источников по-прежнему содержит 456 токенов. Показаны исходные значения и alias-ссылки, включая режимы.
- Четыре интерактивные песочницы: форма с валидацией/сбросом, модальное окно с сохранением и Escape, навигация с вкладками/страницами, таблица с уведомлением и подсказкой.
- Иконки — оригинальные SVG Elastic UI, логотип — экспорт макета; происхождение описано в [icon-origin.md](icon-origin.md).

## Поведение и изменения базы

Продуктовые элементы используют плавную смену цвета/обводки/тени длительностью 150 ms. При `prefers-reduced-motion` переходы отключены. Motion-токены добавлены только в код как явно обозначенный fallback: исходный реестр Figma не содержит этих двух значений.

Добавлены необходимые для композиции входные параметры Select, Modal, Toast и обработчик Pagination. Изолированные Progress Fixed Panel и Slider Track получили контейнеры с корректной высотой. Иконки чекбоксов и радиокнопок теперь отрисовывает исходная библиотека, временные CSS-заглушки удалены.

Light/Dark и три шкалы типографики доступны в панели Storybook. Elastic UI меняет тему; продукт сохраняет утверждённую светлую палитру. Примеры с порталами в AllVariants изолированы в iframe. Исходные Deprecated-компоненты сохранены и подписаны.

- `npm run check`, `npm run lint`, `python execution/audit_react_base.py`: без ошибок; неопределённых CSS-переменных и прямых цветов в стилях компонентов нет.
- `node execution/check_react_showcase.mjs`: 227 компонентов / 3 811 вариантов без падений и сообщений консоли. После исправлений геометрии эти компоненты дополнительно проверены в Storybook.
- `node execution/check_react_interactions.mjs`, `node execution/check_react_completion.mjs`: фильтры, страницы, выбор результата, клавиатура, проигрыватель, поля и меню проходят проверку.
- `node execution/check_storybook.mjs --all`: завершён, 227 отдельных историй, ошибок браузера нет. Проверены полнота индекса и controls, четыре песочницы, переходы, Foundation, оригинальные иконки, autodocs, изменение State и фактическое копирование кода в буфер.
- Дополнительно проверены тёмный фон/малая шкала и загрузка вложенного iframe матрицы Modal.
- `npm run build-storybook` и `npm run build`: успешно. Статический каталог — `storybook-static/`, React-база — `dist/`.

Воспроизводимые JSON-результаты, снимки и журналы: `.tmp/storybook/` и `.tmp/react-base/`. Браузерные тесты используют установленный Chrome.

## Границы и обновление

ParticipantsTable: по запросу пользователя стабилизированы ширины колонок (`table-layout: fixed`), высота области на четыре строки и размеры фильтров. Заголовок и нижняя панель сохраняются при пустом результате; обе кнопки пагинатора отключены. На узком экране горизонтальная прокрутка остаётся внутри таблицы. `check_participants_layout.mjs` сравнивает точные координаты и размеры карточки, колонок, фильтров и пагинатора после переключения страниц, поиска, короткой последней страницы, пустой/единичной выборки, комбинации фильтров и сброса — без смещений. Это поведение React, файл Figma не менялся.

Уточнение после приёмки 24.09: FirstClickTargetRow сверен со всеми шестью вариантами Figma; восстановлены radius=4, иконка bullseye, типографика, интервалы и внутренний фокус. Системные select в фильтрах ParticipantsTable и выборе попытки заменены композицией ProductButton + EUI ContextMenu, чтобы управлять отступами строк и использовать исходные иконки. Проверки `check_rows_and_dropdowns.mjs`, `check_react_interactions.mjs` и основной `check_storybook.mjs` проходят без ошибок; TypeScript, линтер и аудит токенов также проходят.

Автоматический рендер не является попиксельной приёмкой всех вариантов. Адресно просмотрены документация, навигация и библиотека иконок; Accessibility подключён, но полная приёмка доступности не заявляется. Сборка предупреждает о крупных JS-частях, поскольку каталог включает всю библиотеку.

Дополнительные стресс-кейсы сложных компонентов предложены пользователю отдельно по фазе 6; без отдельного ответа не добавлялись и не блокируют основной каталог.

Повторная синхронизация: `python execution/generate_storybook_catalog.py`, затем проверки и сборка. Генератор читает актуальный `src/components/catalog.json`. Повторный init не запускать. Истории импортируют действующие компоненты, поэтому исправления базы попадают в каталог автоматически.
