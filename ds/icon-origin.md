# Источники иконок UX-Lab

24 сентября 2026. Прямое указание пользователя «иконки все бери из наших макетов и дизайн системы» заменяет первоначальное требование React-директивы о плейсхолдерах.

- Исходная библиотека: [Elastic UI, Icons](https://www.figma.com/design/SNBSKtwsO81j3BdjRGFpAw/?node-id=12956-45043). Прочитано 446 компонентов; имена, ключи и ID сохранены в `ds/icon-source-map.json`.
- React использует оригинальные SVG-компоненты закреплённой `@elastic/eui@106.7.0`. В `src/icons.tsx` зарегистрированы 527 ресурсов пакета, чтобы иконки загружались локально. Набор пакета шире прочитанной страницы Figma; это не утверждение, что все 527 входят в макеты.
- Сопоставление исходных имён и ID: `src/components/_shared/sourceIconName.ts`. Алиасы `iInCircle → info`, `questionInCircle → question`, `cross_in_circle → crossInCircle`, `folder_exclamation → folderExclamation` связывают названия Figma с именами той же библиотеки.
- Общий исходный icon-slot `31572:393328` содержит `accessibility`; это его значение по умолчанию. В продуктовых компонентах назначены соответствующие действию иконки библиотеки.
- [Логотип UX-Lab](https://www.figma.com/design/1LeVoicxDT7Sl8TpMPs4hr/?node-id=289-13519) экспортирован в `src/assets/ux-lab-logo.svg`. Тёмная подложка в навигации воспроизводит родительский ProductMark в макете.

Foundation/Icons показывает только сопоставленные исходные компоненты; брендовые варианты, для которых нет однозначного имени в установленном пакете, не подменяются похожими иконками. Исходники не перерисованы, Lucide и сторонние наборы не добавлены. `execution/sync_design_icons.py` воспроизводит регистрацию SVG из установленного пакета. Временные URL Figma в коде не используются. Файл Figma в этой задаче не изменялся.
