# React Base — отчёт переноса

Дата: 24 сентября 2026. Рабочая база доступна на локальной странице Vite. Фаза реализации и автоматических проверок завершена; страница подготовлена для визуальной приёмки из фазы 5 директивы.

## Состав

| Область | Результат |
| --- | --- |
| Стек | Vite 8.3, React 18.3, TypeScript 5.9 |
| Исходная библиотека | EUI 106.7.0, Amsterdam, версия закреплена |
| Реестр | 204 позиции Elastic + 23 позиции UX-Lab |
| Варианты | 3 811 сочетаний исходных осей |
| Токены | 456: 273 локальных Elastic, 81 продуктовый, 102 внешних зависимости |
| Типографика | 29 Text Styles, локальные Inter и Roboto Mono |
| Отсутствующие позиции реестра | Нет |

Имена Figma и ID сохранены в `ds/react-name-map.json` и `src/components/catalog.json`. Для имён, недопустимых в TypeScript, предусмотрены однозначные имена экспортов. 57 исходных Deprecated-позиций сохранены с пометкой; новая версия дизайн-системы не подставлялась.

Семантические CSS-переменные ссылаются на примитивы или другие исходные aliases. Собственная палитра UX-Lab отделена от исходных Light/Dark Elastic. Значения темы EUI формируются из выгруженного манифеста; продуктовая тема остаётся светлой, как утверждённый макет.

## Завершённые уточнения

- ScenarioTable: заголовок и пояснение вне поверхности таблицы; шесть столбцов, показатели, границы, чередование строк, выбранная строка, взаимоисключающий выбор сценария, состояния загрузки/ошибки/пустой выборки. Переходы передаются через callbacks.
- ParticipantsTable: реальные страницы демонстрационной выборки, совместные фильтры, поиск ID, сброс, выбор попытки, недоступность стрелок на границах.
- TaskChoiceCard: Radio, светло-зелёный выбранный фон, подпись выбора, focus и disabled. TaskResultControl отделяет результат задания от «Далее».
- SuccessMetric: доля и процент, индикатор, база расчёта; нулевой показатель отличается от отсутствия оценки.
- Внутренние части Elastic Form, Markdown, Page Layout, Popover, Range, SuperDatePicker, Tour и Table имеют отдельные адаптеры. Служебные пояснения к полям больше не выводятся как поля ввода.
- Исправлены группы фильтров и фасетов, отдельные элементы breadcrumbs и button group, части code block, боковая навигация, timeline и список уведомлений.
- Стили страницы каталога ограничены его собственными контролами. Они больше не меняют расположение подписей Radio внутри компонентов.
- В каталоге доступны не только варианты, но и текстовые/логические свойства Figma. Переключение вариантов сохраняет допустимые комбинации исходной матрицы.
- ReplayControls: пропорциональная шкала и разрыв данных, перемотка с клавиатуры и кнопками, границы записи, скорость, состояние воспроизведения, fullscreen и callbacks. AttemptAction раскрывает список попыток.
- Сверены и уточнены AutoRefresh, компактный выбор даты, карточки Radio/Checkbox, миниатюры компоновок, группы аватаров, вложенная навигация и геометрия Range. Очистка файла сбрасывает также нативное поле.
- Устранена нулевая высота раскрытой навигации: старый EuiObserver из закреплённой EUI 106 отключается при пробном unmount в React StrictMode и не подключается повторно. Каталог запускается без StrictMode; раскрытие и сворачивание проверяются по фактической высоте содержимого, а не только aria-expanded.

## Визуальная сверка и ограничения

Figma MCP использовался для чтения исходных ID, матриц, токенов и состава. Адресно просмотрены экспорты продуктовых таблиц и карточек выбора, частей полей, Markdown, диапазона, дат, навигации и всплывающих элементов; исправлена обнаруженная ошибка геометрии Radio в каталоге.

Это **не попиксельная приёмка всех 3 811 вариантов**. Полный автоматический рендер доказывает работоспособность каталога, но не идентичность каждого внутреннего отступа или всех промежуточных состояний Figma. Оставшиеся визуальные расхождения должны фиксироваться по конкретному компоненту/варианту при просмотре тестовой страницы. Не использовать число фасадов как отдельное доказательство полной визуальной идентичности.

При первоначальной сдаче иконки были прозрачными заглушками согласно React-директиве. В рамках следующей задачи Storybook пользователь поручил использовать исходные иконки: теперь подключены SVG Elastic UI и логотип из Figma (см. `icon-origin.md`). Иллюстративные изображения представлены местами для контента. Данные демонстрационные; API аналитики, настоящая запись сессий и маршрутизация экранов не входят в React Base. Storybook описан отдельным отчётом `storybook-report.md`.

Production build предупреждает о крупном пакете каталога: около 5,38 MB JS / 1,18 MB gzip. Каталог показывает всю библиотеку сразу. Разделение загрузки для пользовательского приложения ещё не выполнялось и не маскируется увеличением лимита предупреждения.

Запуск и использование компонентов описаны в корневом `README.md`.
