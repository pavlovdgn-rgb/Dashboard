# StudySetup — Настройка исследования

**Размер:** desktop 1920×1080 px.
**Статус:** отрисовано и проверено. [Открыть Figma](https://www.figma.com/design/1LeVoicxDT7Sl8TpMPs4hr/Dashboard?node-id=32-3).
**Основание:** 21 сентября 2026 пользователь поручил немедленно нарисовать предложенные экраны проектов, исследований, настройки и запуска. Повторных апрувов не требуется.

## Структура и поведение

- Header 64 px, Sidebar 240 px, Main 1680 px. Путь: проекты / проект / исследование.
- Два этапа: настройка; проверка и запуск. Состояние черновика и сохранения видно отдельно.
- StudyForm 1016 px: обязательное название, выбор «Задания / Свободное изучение», стартовый URL прототипа, список сценариев и добавление. Демонстрация показывает уже заполненный черновик.
- Каждая карточка задания: номер, название, текст участнику, резюме критерия и действия изменить/настроить критерий. Добавление позволяет ввести текст или выбрать из списка; редактор задания здесь не отрисован отдельным состоянием.
- «Критерий успеха» открывает существующее представление SuccessCriteria в контексте выбранного задания; пример про заказ в другом wireframe не подставляется автоматически.
- ConnectionPanel 576 px: инструкция установки кода, плейсхолдер выдаваемого кода, копирование, проверка, статус и время приёма контрольных событий. URL example.test, время и успех проверки — демонстрационные. Реальный SDK не подключался.
- Кнопки «Сохранить черновик» и «К проверке и запуску»; переход сохраняет данные, при ошибке остаётся на форме. Сохранение не начинает сбор.
- В свободном режиме задания/критерии не обязательны. Участнику показывается инструкция свободного изучения. Ошибки обязательных полей — локально; подключение различает ожидание, полученные события и ошибку. Несохранённый ввод не теряется при ошибке сохранения.

## Границы макета

Редактируемый low-fi с Auto Layout, Inter Regular/Medium и согласованной монохромной палитрой. Данные искусственные, кнопки не подключены к работающему сервису. Альтернативные состояния описаны выше; кроме явно показанного состояния, отдельные фреймы для них не создавались. Метод привязки целей, правила попыток и хранения не меняются этим макетом.

Воспроизводимая сборка: `execution/build_project_wireframes.py`. Размещение: Dashboard → UX-Lab · Wireframes → Wireframes — Projects & Launch.
