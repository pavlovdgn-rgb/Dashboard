# SWOT конкурентов

Дата: 18 сентября 2026 года. Контекст: внутренний сервис для дизайнеров и PM; два коллеги, 2–5 одновременных участников, 20 участников исследования. Главный приоритет — тепловые карты; весь объём первой версии сохраняется.

Основания: [бриф](brief.md), [быстрый анализ](competitive_analysis.md), [полученный глубокий отчёт](deep_research_results.md.md) и точечная проверка первоисточников. UX оценён по документации, без самостоятельного тестирования кабинетов. Возможности конкурентов учитываются независимо от тарифа; ограничения указаны отдельно. Наш продукт находится на стадии плана.

S/W описывают конкурента относительно брифа; O/T — наши аналитические гипотезы, а не прогнозы вендоров.

## Maze

### Strengths — сильные стороны конкурента

- Исследования с заданиями и ожидаемыми путями. [M1](https://help.maze.co/articles/2471284614-website-test-run-usability-tests-on-your-live-websites)
- Карты первого клика и разбор исходов участников. [M2](https://help.maze.co/articles/4467546573-understanding-your-live-website-test-results)

### Weaknesses — ограничения относительно брифа

- Шаги Website Test завязаны на изменение URL. [M1](https://help.maze.co/articles/2471284614-website-test-run-usability-tests-on-your-live-websites)
- Первый снимок страницы не отражает последующие модальные состояния. [M2](https://help.maze.co/articles/4467546573-understanding-your-live-website-test-results)

### Opportunities — возможности для нас

- Проверить преимущество целей по событиям внутри страницы.
- Связать карту с конкретным состоянием интерфейса.

### Threats — угрозы для нас

- Близость готового процесса уменьшает выгоду собственной разработки.
- Устранение ограничений карт сузит предполагаемое отличие.

## UXtweak

### Strengths — сильные стороны конкурента

- Сценарное тестирование сайтов и приглашение по ссылке. [U1](https://www.uxtweak.com/website-usability-testing-tool)
- Отдельные DOM-записи, карты и поиск сессий. [U2](https://www.uxtweak.com/session-recording-tool/)

### Weaknesses — ограничения относительно брифа

- Бесплатный Website Testing: три ответа и одно задание. [U3](https://www.uxtweak.com/pricing/)
- Отдельный Session Recording в тарифной матрице относится к Custom. [U3](https://www.uxtweak.com/pricing/)

### Opportunities — возможности для нас

- Упростить выбор между тестом с заданием и свободным режимом.
- Объединить результаты исследования и PDF в одном процессе.

### Threats — угрозы для нас

- Набор исследовательских инструментов уже широкий.
- Настройка платного плана может оказаться дешевле поддержки своего сервиса.

## Microsoft Clarity

### Strengths — сильные стороны конкурента

- Бесплатные карты и записи. [C5](https://clarity.microsoft.com/)
- Воронка связана с отфильтрованными картами и сессиями. [C2](https://learn.microsoft.com/en-us/clarity/setup-and-installation/funnels)

### Weaknesses — ограничения относительно брифа

- Содержимое input-полей всегда скрыто. [C3](https://learn.microsoft.com/en-us/clarity/setup-and-installation/clarity-masking)
- Для нашего процесса не подтверждён конструктор заданий — пробел проверки, не доказанное отсутствие.

### Opportunities — возможности для нас

- Добавить понятную настройку задания и результата участника.
- Сделать просмотр ввода частью исследования согласно брифу.

### Threats — угрозы для нас

- Бесплатная аналитика ослабляет ценовой аргумент.
- Команде может хватить готовых карт и отдельного процесса заданий.

## Contentsquare / Hotjar

### Strengths — сильные стороны конкурента

- Связь карт с replay при сохранении фильтров. [S2](https://support.contentsquare.com/hc/en-us/articles/37271710955793-How-to-create-Heatmaps-and-Zonings)
- Insights открывает контекст проблемного события. [S3](https://support.contentsquare.com/hc/en-us/articles/37271802041745-Insights-and-Session-Replay)

### Weaknesses — ограничения относительно брифа

- Free записывает replay только для доли сессий. [S1](https://contentsquare.com/pricing/)
- Просмотр ввода через Controlled Exposure требует специального подключения. [S4](https://docs.contentsquare.com/en/web/personal-data-handling/)

### Opportunities — возможности для нас

- Показывать полноту данных каждого приглашённого участника.
- Сделать небольшое исследование основной единицей навигации.

### Threats — угрозы для нас

- Визуальный анализ уже развит и доступен на нескольких тарифах.
- Просмотр ввода не является нашей исключительной возможностью.

## PostHog

### Strengths — сильные стороны конкурента

- Событийные воронки и переход к поведению участников. [P4](https://posthog.com/docs/product-analytics/funnels)
- Карты, replay и настраиваемое маскирование. [P1](https://posthog.com/docs/toolbar/heatmaps) [P2](https://posthog.com/docs/session-replay) [P3](https://posthog.com/docs/session-replay/privacy)

### Weaknesses — ограничения относительно брифа

- Нужно настроить модель событий под задания; готовый конструктор не подтверждён.
- Отображение карты зависит от страницы и настроек сбора; есть ограничения встраивания. [P1](https://posthog.com/docs/toolbar/heatmaps)

### Opportunities — возможности для нас

- Представить события языком заданий и целей дизайнера.
- Сохранять контекст исследования до подготовки PDF.

### Threats — угрозы для нас

- Бесплатные квоты покрывают значительный объём аналитики. [P5](https://posthog.com/pricing)
- Гибкие настройки уменьшают число функций, требующих собственного инструмента.

## Как учтён глубокий отчёт

Документ `deep_research_results.md.md` использован как набор аналитических гипотез. Он сообщает об ограниченном сборе данных, не содержит реестра заявленных примерно 45 отзывов и заменяет ссылки названиями «парадигм». Поэтому частота жалоб, годовая динамика рейтингов и наличие свободной ниши не считаются доказанными.

| Утверждение исходного отчёта | Решение в финальном анализе |
| --- | --- |
| Немаскированный ввод практически невозможен в PostHog | Исправлено: документация разрешает настраивать маскирование input-полей. [P3](https://posthog.com/docs/session-replay/privacy) |
| Contentsquare не может показывать ввод | Уточнено: есть Controlled Exposure для Experience Monitoring, требующий активации; универсальный запрет неверен. [S4](https://docs.contentsquare.com/en/web/personal-data-handling/) |
| 20 участников покрываются любым бесплатным тарифом | Исключено: UXtweak Free Website Testing ограничен тремя ответами. [U3](https://www.uxtweak.com/pricing/) |
| 20 участников гарантируют 85% проблем и не позволяют количественные метрики | Исключено: смешаны разные методики; статья NN/g о пяти участниках не даёт такой гарантии нашему тесту, а отдельная статья обсуждает количественные исследования с 20 участниками. [N1](https://www.nngroup.com/articles/quantitative-studies-how-many-users/) [N2](https://www.nngroup.com/articles/why-you-only-need-to-test-with-5-users/) |
| Первый клик гарантирует 87% успеха; карты при n=20 надёжны | Не перенесено: нет проверяемого основания и условий применимости в отчёте |
| PostHog требует SQL | Исправлено: у воронок есть визуальный конструктор; SQL — один из вариантов фильтрации. [P4](https://posthog.com/docs/product-analytics/funnels) |
| Ниша освободилась, отзывы подтверждают массовый спрос | Оставлено гипотезой: нет корпуса отзывов, исторических снимков и сопоставимой выборки |
| Разработка заведомо невыгодна, хранение стоит $10–20/мес. | Числа и категоричный вывод исключены: нет замера объёма, бюджета и стоимости труда |
| Нужно скрыть карты в спойлере | Отклонено: противоречит главному приоритету брифа |

Описание сессии как «тяжёлого видео» не принято за архитектурное требование: существуют реконструируемые DOM-записи. [U2](https://www.uxtweak.com/session-recording-tool/) Способ реализации нашего replay пока не выбран. Юридические выводы исходного отчёта не используются как доказательство технических возможностей продуктов.
