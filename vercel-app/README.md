# UX-Lab для Vercel

Самостоятельная версия приложения. Корневая локальная версия сохраняется отдельно.
Дашборд, Lead Generation и Python API публикуются одним проектом Vercel.
Данные сохраняются в **Turso с движком libSQL**. Постоянной базы в `/tmp` нет.

## Размещение

1. Создайте базу в [Turso](https://turso.tech/) **с движком libSQL** и получите её URL и токен. Драйвер этой версии — `libsql`, не `turso_serverless`.
2. В Vercel импортируйте `pavlovdgn-rgb/Dashboard` либо измените настройки существующего проекта.
3. В **Settings → Build and Deployment → Root Directory** укажите `vercel-app`.
4. Framework Preset: **Vite**. Команды заданы в `vercel.json`: установка `npm ci && npm ci --prefix participant`, сборка `npm run build`, результат `dist`.
5. В **Settings → Environment Variables** добавьте:

| Имя | Значение |
| --- | --- |
| `TURSO_DATABASE_URL` | URL libSQL-базы, например `libsql://…turso.io` |
| `TURSO_AUTH_TOKEN` | Токен этой базы |
| `UXLAB_ACCESS_PASSWORD` | Случайный пароль рабочего пространства, минимум 12 символов |

Не добавляйте префикс `VITE_`: эти секреты не должны попадать в браузер.
Для Preview используйте отдельную тестовую базу либо включите переменные только для Production.

6. Выполните **Redeploy**. Схема пустой базы создаётся при первом авторизованном запросе.
7. Откройте сайт, введите пароль. В «Проверка и запуск» откройте интерфейс, выполните действия и проверьте сессию и клики в дашборде.

Дашборд: `/#/projects`. Интерфейс участника: `/participant/leads-table?ux_study=leed-local`.
Ссылка для участника формируется с доменом текущего размещения.
`/api/health` проверяет запуск функции и наличие настроек. Успешная загрузка исследования дополнительно проверяет соединение с базой.

## Возможности

- Исследования, настройки, посещения, клики, тепловая карта, задания, результаты, находки и отчёты.
- Сохранённые снимки и воспроизведение событий; значения полей в снимках маскируются.
- WebM по действию участника и разрешению браузера, воспроизведение, перемотка и скачивание.
- PNG и ZIP карт формируются в браузере по сохранённым снимкам. Chrome на Vercel не требуется.
- PDF формируется сервером с включёнными шрифтами Noto Sans и лицензией OFL.
- Общий пароль, подписанная HttpOnly-cookie на семь дней. Смена пароля отзывает прежние cookie.

Это небольшое общее рабочее пространство. Участники с паролем получают доступ **ко всему дашборду**; отдельные роли и личные кабинеты не добавлены.
Пилот подключения произвольных сторонних сайтов не включён: здесь собираются данные опубликованного Lead Generation.
Локальная история **не переносится автоматически**: облачная база начинает работу без событий пользователя.

## Хранение

Видео тоже хранится в Turso; Vercel Blob для этой версии не нужен. Загрузка идёт блоками до 256 КиБ, ответы с видео ограничены 1 МиБ, браузер собирает файл при скачивании.
Одна запись ограничена примерно 30 минутами и 256 МиБ на сервере. Это предел приложения, а не объём бесплатного тарифа базы.
Для большой видеотеки потребуется объектное хранилище. Существующие запросы аналитики также требуют оптимизации для большой истории; текущая версия рассчитана на пилот.
Лимиты и стоимость Turso учитываются отдельно от Vercel.

## Проверки

```sh
npm ci
npm ci --prefix participant
npm run build
python -m pip install -r requirements.txt
python tests/test_cloud_api.py
```

HTTP-тесты используют реальные обработчики с изолированной временной SQLite: авторизация, маршруты, повторы, откат транзакции, сохранение между запросами, исследования, снимки, PDF и видеодиапазоны.
Они **не заменяют проверку соединения с вашей Turso после размещения**.

Для браузерной проверки задайте `UXLAB_TEST_DB` с путём к новой временной базе вне исходников и `UXLAB_ACCESS_PASSWORD=test-password-cloud-123`. Запустите `python execution/preview.py`, затем в другом терминале `node tests/browser.mjs` (нужен Chrome).
Тест видео использует синтетический canvas, не экран пользователя. В production `UXLAB_TEST_DB` игнорируется.

Источники: [Vercel Python](https://vercel.com/docs/functions/runtimes/python), [Turso Python](https://docs.turso.tech/sdk/python/quickstart), [лимиты Vercel](https://vercel.com/docs/functions/limitations).

Подготовлено 5 октября 2026 года. Для реального размещения обязательны подключённая база и переменные окружения.
