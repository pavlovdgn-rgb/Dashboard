# Конкурентный анализ: внутренний сервис UX-тестирования

Дата: 18 сентября 2026 года. Контекст: внутренний сервис для дизайнеров и PM; два коллеги, 2–5 одновременных участников, 20 участников исследования. Главный приоритет — тепловые карты; весь объём первой версии сохраняется.

Основания: [бриф](brief.md), [быстрый анализ](competitive_analysis.md), [полученный глубокий отчёт](deep_research_results.md.md) и точечная проверка первоисточников. UX оценён по документации, без самостоятельного тестирования кабинетов. Возможности конкурентов учитываются независимо от тарифа; ограничения указаны отдельно. Наш продукт находится на стадии плана.

## 1. Executive summary

Проекту стоит доказывать удобство полного цикла небольшого UX-исследования, поскольку многие отдельные функции уже есть у конкурентов. Maze и UXtweak — ближайшие ориентиры для заданий, а Clarity, Contentsquare и PostHog — для поведенческой аналитики. [M1](https://help.maze.co/articles/2471284614-website-test-run-usability-tests-on-your-live-websites) [U1](https://www.uxtweak.com/website-usability-testing-tool) [C2](https://learn.microsoft.com/en-us/clarity/setup-and-installation/funnels) [S2](https://support.contentsquare.com/hc/en-us/articles/37271710955793-How-to-create-Heatmaps-and-Zonings) [P4](https://posthog.com/docs/product-analytics/funnels) Бесплатные предложения Clarity и PostHog ослабляют аргумент экономии на подписках. [C5](https://clarity.microsoft.com/) [P5](https://posthog.com/pricing) Уникальных функций по проверенным данным не установлено, в том числе просмотр ввода имеет аналоги с настройками или особыми условиями. [P3](https://posthog.com/docs/session-replay/privacy) [S4](https://docs.contentsquare.com/en/web/personal-data-handling/) Главный проектный приоритет — тепловые карты с переходом к участнику и записи в контексте задания. Заявления глубокого отчёта о частоте жалоб, динамике рынка и гарантированной окупаемости не имеют достаточных подтверждений и не использованы как факты. Решение о разработке следует опереть на проверку сквозного прототипа и оценку затрат, сохраняя весь согласованный объём первой версии.

## 4. UX-паттерны: стандарт и рекомендации

Повторяющиеся ожидания: понятное подключение, выбор контекста и доступ к деталям поведения; одинаковый конструктор заданий у всех пяти не подтверждён.

- **Maze:** взять организацию результатов вокруг задания; карта остаётся главным экраном анализа. [M2](https://help.maze.co/articles/4467546573-understanding-your-live-website-test-results)
- **Clarity / PostHog:** переходить из шага воронки к соответствующим участникам и записям. [C2](https://learn.microsoft.com/en-us/clarity/setup-and-installation/funnels) [P4](https://posthog.com/docs/product-analytics/funnels)
- **Contentsquare:** сохранять фильтры при переходе к replay и открывать контекст перед проблемой. [S2](https://support.contentsquare.com/hc/en-us/articles/37271710955793-How-to-create-Heatmaps-and-Zonings) [S3](https://support.contentsquare.com/hc/en-us/articles/37271802041745-Insights-and-Session-Replay)
- **UXtweak:** использовать поиск записей и пропуск неактивных промежутков. [U2](https://www.uxtweak.com/session-recording-tool/)

Точки расхождения: цели по URL либо событиям, экранная запись либо DOM-replay, карта страницы либо её состояния. Для нашего продукта предложены общие фильтры задания/устройства и отдельная настройка критерия успеха. Результат показывать как «8 из 20 — 40%» с объёмом выборки; сами 20 участников не являются основанием ни для запрета количественных метрик, ни для обещания точности. [N1](https://www.nngroup.com/articles/quantitative-studies-how-many-users/)

## 5. Выводы: дифференциаторы и риски

**Потенциальное отличие:** единый процесс небольшого исследования с картой в центре анализа и сохранением контекста до PDF. Возможность быстрее выполнить этот процесс ещё нужно измерить. Отдельные карты, replay, первый клик и просмотр ввода не доказывают уникальность.

| Риск / ограничение | Конкретное действие |
| --- | --- |
| Готовые бесплатные инструменты уже закрывают значительную часть аналитики [C5](https://clarity.microsoft.com/) [P5](https://posthog.com/pricing) | Сравнить время запуска и разбора одного одинакового исследования, затем оценить полную стоимость собственного решения |
| Не определена связь текста задания с успехом | Прототипировать выбор целевой страницы, кнопки и цепочки; проверить сценарий без смены URL |
| Карта может смешивать устройства и состояния | На контрольном интерфейсе проверить модалку, изменение разметки, мобильный экран и переходы |
| Неполные записи могут искажать выводы | Отдельно показывать полноту данных и число участников, вошедших в каждую метрику |
| Содержимое полей хранится в записи | Реализовать подтверждённое требование с явными правилами доступа, хранения и удаления; решения пока открыты в брифе |
| Глубокий отчёт не подтверждает спрос и окупаемость | Проверить гипотезу на двух коллегах; не использовать недоказанные рейтинги, проценты и цены в обосновании |

**Рекомендуемое следующее действие:** проверить сквозной прототип «подключение → задание → ссылка → карта → запись → PDF» на работающем интерфейсе. Зафиксировать время настройки, возможность найти проблему и совпадение данных с контрольными действиями. Целевые пороги пока не утверждены; полный функциональный объём первой версии сохраняется.
