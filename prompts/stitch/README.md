# Промпты для Google Stitch

Два самостоятельных JSON-дизайн-задания, подготовлены 22 сентября 2026 по актуальным Figma-фреймам.

- [01_participants.json](01_participants.json) — Участники исследования, исходная ссылка 49:85, полный экран 49:79.
- [02_first_click_heatmap.json](02_first_click_heatmap.json) — Тепловая карта / Первый клик, исходная ссылка 50:143, полный экран 50:137.

Содержимое каждого JSON можно использовать целиком как текст промпта. Это структурированное описание задания, а не заявленная схема API или специального импорта Stitch. Если используете изображения как вход, соответствующий скриншот wireframe поможет передать компоновку; всё содержимое экрана уже включено в текст.

Оба файла самодостаточны. У них одинаковые палитра, оболочка, типографика и меню. Для второго экрана стоит также использовать первый получившийся UI как визуальный ориентир общей оболочки. Ссылки Figma не предполагают, что Stitch автоматически импортирует библиотеку.

В промптах сохранены реальные тексты макетов и демонстрационные числа. Служебные пояснения заменены понятными подписями: коды D02 не выводятся в продуктовый UI. Оливковая карта соответствует текущему UI Kit; красный #C61E25 остаётся только цветом позиции воспроизведения и на этих двух экранах не применяется.

Генератор: execution/create_stitch_prompts.py. Проверены валидность обоих JSON, совпадение общего стиля и сумма распределения 18 первых кликов. Генерация UI в самом Stitch не запускалась.
